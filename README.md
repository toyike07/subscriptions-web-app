# subscriptions-web-app

Esta es una aplicación web diseñada para gestionar suscripciones de diferentes servicios (Netflix, Spotify, etc.). Está diseñada como una **Progressive Web App (PWA)** para que pueda ser utilizada como una app desde la pantalla de inicio de dispositivos móviles.

## Instrucciones para acceder:

Actualmente el despliegue se encuentra en proceso y pronto será accesible desde GitHub Pages. Una vez publicada, podrás usarla directamente desde tu navegador y añadirla a tu pantalla de inicio en Safari. Actualizaremos las instrucciones en este archivo cuando esté lista.
